# 📊 Customer Behavior Analysis

> End-to-end customer analytics project analyzing shopping behavior to uncover purchasing trends, customer segments, and revenue-driving insights using **Python, SQL, Excel, and Power BI**.

## 📌 Project Overview

This project analyzes **5,000+ customer transactions** to identify customer purchasing behavior, product performance, revenue trends, and high-value customer segments.

The complete analytics workflow includes:

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- SQL Business Analysis
- Interactive Power BI Dashboard
- Business Recommendations
